# Scope

Read any existing documents in the **change folder**.

A **journey** is one entry point, one goal, one continuous user experience.

If the request is already one journey, Scope is done.

If it spans multiple journeys: propose a breakdown with a change name per piece, **Choice** which to brief now, wait. This run continues for the chosen piece — update the name and the **change folder** to match. A tracker entry the run started from is left as it is.

Scope is done when this run's name is one **journey**.
