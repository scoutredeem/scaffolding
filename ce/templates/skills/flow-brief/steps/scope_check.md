If the request is already one journey, Scope is done.

If it spans multiple journeys: propose a breakdown with a change name per piece, **Choice** which to brief now, wait. This run continues for the chosen piece — update the name, the **change folder**, and tracker identity to match.

Scope is done when this run's name is one **journey**.
